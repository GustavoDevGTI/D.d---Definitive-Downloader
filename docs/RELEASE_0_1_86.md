# Definitive Downloader 0.1.86 para Windows

- Cartões de Minhas coleções com contagem de faixas e downloads, grupo e andamento da conferência.
- Confirmação da versão escolhida com o botão Usar esta versão.
- Conferência com pausa, retomada, contagem de faixas e estimativa de tempo. Outras playlists podem ser importadas durante a busca.
- Capas personalizadas e criação de playlists ao arrastar pastas de áudio para Minhas coleções.
- Gerenciador de downloads mostra as faixas enviadas para a fila.
- Atalho Importar playlist disponível na tela inicial.

Instalador Windows x64. A integridade do instalador pode ser conferida em SHA256SUMS.txt.
